Usage Requirements
The TopDeck.gg API is
free to use
, providing tournament data for your projects and applications.
Rate Limits
Most endpoints allow
100 requests per minute
. Heavier endpoints like bulk tournament queries have lower limits. You'll receive a
429
response if you exceed your limit. Need more? E-mail us at
[email protected]
.
Attribution Required
Any project using the API must include a visible credit and link back to TopDeck.gg. See the attribution example on the right.
Info
By using the API, you agree to these requirements. Thank you for supporting TopDeck.gg!
Quick Start
curl https://topdeck.gg/api/v2/tournaments \
  -H "Authorization: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"game": "Magic: The Gathering", "format": "Standard", "start": 1700000000}'

Staff View
Building a tool for an event you staff? Add
?view=staff
to a single-tournament read —
/v2/tournaments/{TID}
,
/standings
,
/players/{ID}
,
/players/{ID}/table
,
/rounds
,
/rounds/latest
or
/rounds/{n}
— to see decks as the tournament manager shows them to staff:
decklist
,
deckObj
,
archetype
and
archetypeInput
while the event runs, and
leader
before it starts.
Your API key's account must hold a staff role on that tournament (any role — the same check as
/attendees
); otherwise the request returns
403
. Without the parameter, every read follows the public rules. Contact details (email, Discord) stay on
/attendees
.
Staff-view responses are never cached. Decklists make them larger, so poll
/rounds/latest
or
/players/{ID}/table
rather than the full tournament.
Example Request
curl "https://topdeck.gg/api/v2/tournaments/{TID}/rounds/latest?view=staff" \
  -H "Authorization: YOUR_API_KEY"

/v2/tournaments
Search completed tournaments. Returns standings, decklists, and optional round data. Filter by TID, or by game + format + date range.

also returns

For leader-based games — Riftbound (the Legend) and Magic commander formats (the commander) — standings rows and round players also carry a
leader
string: the deck's leader card name(s). Two cards (partners, a background) appear in alphabetical order as
"A / B"
, and a double-faced card by its front face, so the same deck always reads the same. It is always included (no column request needed) and absent when there is no deck or the event has not started yet.
For every other game, standings rows and round players carry an
archetype
string: the deck's archetype label. It is a staff correction, else the player's own name for the deck when it holds up against the decklist, else an automatic label (deck rules for Magic 60-card formats). Alongside it,
archetypeInput
is the name the player typed for the deck, as typed — it can differ from
archetype
(a nickname, or a name the decklist contradicts). Both are present once decklists are public (the event has ended, or the organizer enabled "Show Decks"); each is absent without a value.
Selecting
winner
in
tables
also returns
winner_id
. For 1v1 (Pairs) matches it additionally returns the per-match game score as
winner_games
and
loser_games
(
null
for multiplayer pods and score-based formats).
For team events (e.g. Trios), each standing is one team:
name
is the combined team name,
id
and
decklist
belong to the team captain, and a
players
array lists the roster (
id
,
name
,
teamTag
, plus decklists when the
decklist
column is requested). Round tables are per-seat sub-matches: tables from the same team pairing share a
match
key, and each player carries their
teamTag
when the organizer configured format tags.

POST
/v2/tournaments/create
Create a tournament owned by your API key's account. Include
eventPage
to also create a public, discoverable event page with registration; omit it for an unlisted, bracket-only tournament.
Note
Requires an active
TopDeck subscription
. Limited to
10 requests per minute
.
Payments
Payment processing (Stripe/PayPal) cannot be enabled through the API. Configure payments from the web dashboard after creating the event.

POST
/v2/tournaments/{TID}/register
Register one or more players by email. Emails matching an account are registered immediately; emails without an account receive an invitation and convert on signup. Returns
409
if the request would exceed the event's player cap — pass
overrideCap: true
to bypass.
Staff Only
Requires
admin
role or higher.

Field
Type
Description

string | string[]
