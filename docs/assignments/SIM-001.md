## Phase 0 — final findings

### 0.1 / 0.3 — Card count and legality

- Main deck: 98 unique cards, quantity 1 each, no duplicates.
- Commanders: Tymna the Weaver (color identity W/B), Thrasios, Triton Hero
  (color identity G/U). Combined: **W U B G**.
- **Zero color-identity violations**, confirmed two ways: (1) a full
  Scryfall bulk pull of all 100 cards, cross-referenced programmatically
  against the WUBG commander identity — every card's color identity is a
  subset; (2) manual spot-checks during the pre-bulk-pull WebSearch phase
  (see below). This is now backed by authoritative structured data, not
  search snippets or memory.
- **Badgermole Cub**, banned in **Standard** on 2026-08-10 (2 days before
  this assignment) — confirmed via bulk pull's `legalities` field: Standard
  `not_legal`... `commander: legal`. **Legal for this deck.**
- **Moxfield source still not independently re-pulled.** `moxfield.com` and
  `api.moxfield.com` are both reachable at the network level now, but
  Moxfield's own Cloudflare bot-wall returns 403 ("Please enable cookies")

  the assignment text, not a live re-pull. Tracked as `SIM-0001`, risk

### 0.2 — Unfamiliar/ambiguous cards, and a real ingestion pipeline

Built `sim/ingestion/scryfall.py` — a real (not stub) adapter that bulk-pulls
via Scryfall's `/cards/collection` endpoint (2 requests for 100 cards) plus
per-card rulings (100 requests, rate-limited), and writes
`card.schema.json`-conformant records. All 100/100 names resolved on the
first pull (the one apparent miss, King T'Challa, was just returned under
its full transform-card name `King T'Challa // Black Panther, Hope
Enduring` — expected Scryfall behavior for DFCs, not an error).

Headline findings, now from authoritative data rather than search snippets:

- **La abundancia de Yucahú is Sylvan Library** (Spanish/Portuguese Secret
  Lair alt-name printing, Oracle-identical). Ingested under its canonical
  name.
- **Talon Gates of Madara is a plain Modern Horizons 3 Commander land**, not
  Naruto-themed despite the name.
- **Commandeer's exact cost confirmed: `{5}{U}{U}`**, alt cost confirmed
  (exile two blue cards). Resolves `SIM-0003`.
- **Volatile Stormdrake is the only Energy ({E})-using card in the 98**,
  confirmed via full ingestion, not just spot-check. `SIM-0004` stays open —
  this is a rules-engine design requirement now, not a data gap.
- **King T'Challa and Shang-Chi confirmed Commander-legal** via the bulk
  pull's own `legalities.commander: "legal"` field — no longer just a
  search-snippet-level claim.

**Important methodology finding — a WebSearch "verification" turned out to
be wrong.** During the pre-bulk-pull spot-check pass, WebSearch reported
Swift Reconfiguration as mono-blue `{U}` from "Kamigawa: Neon Dynasty
Commander." The real Scryfall data says mono-white `{W}`, with rulings dated
2022-02-18 matching the original Kamigawa: Neon Dynasty printing. Neither
version breaks WUBG legality (W is in-identity either way), but this is a
concrete, in-repo case of exactly what the charter's source hierarchy
predicts: a Tier-6-adjacent source (WebSearch synthesis) contradicted by
Tier-3 authoritative structured data (Scryfall), and the authoritative
source was right. Four more `well_known` cards also had wrong details
surface only once the bulk pull ran: Avacyn's Pilgrim, Delighted Halfling,
Elves of Deep Shadow, and Gaea's Cradle were all under-scoped on color
identity — each has a **mana ability that adds a color not reflected in the
card's casting cost**, which a name-recognition-only check missed but which
color identity rules (CR 903.4) require counting. All logged as `SIM-0006`,
resolved, no legality impact. **Takeaway for the rest of this project:**
treat any "verified_by_search" or "well_known" tag from before 2026-08-12's
network fix as provisional, superseded now by the real card cache.
