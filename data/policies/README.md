# Policy definitions

Empty. Blocked on the archetype registry existing first (`data/archetypes/`)
and, for the subject deck's own policy, on the decklist. See
`docs/POLICY_FRAMEWORK.md` for the required shape and
`data/schemas/policy.schema.json` for the schema. One subdirectory per
`archetype_id`, versioned files inside (`v1.json`, `v2.json`, ...).
