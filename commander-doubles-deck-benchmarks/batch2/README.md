## Reproduce from repository root

Use the existing Python environment/requirements. No paid API or network is needed.

~~~sh
python commander-doubles-deck-benchmarks/build_batch2.py
python commander-doubles-deck-benchmarks/build_batch2.py --check
python -m unittest discover -s commander-doubles-deck-benchmarks/tests -p test_batch2.py -v
python commander-doubles-deck-benchmarks/score_batch2.py commander-doubles-deck-benchmarks/batch2/decks/D1.txt --deck-b commander-doubles-deck-benchmarks/batch2/decks/D2.json --summary
~~~

Inputs: deck_inputs.json, review_content.json and research/ frozen facts/authorities. Build does not acquire new external data. --check compares generated bytes without writing. JSON decks wrap Oracle-keyed submitted_deck plus version/checksum metadata; text uses Commander/Deck sections. Editing a CSV is not a price override: revise the versioned adapter only after organizer decisions. Full card/location authority and checksums are supplied.

Source reuse is limited to permitted existing factual event snapshots, attributed primary research and original analysis. No full source primers/images are redistributed. Public Moxfield shells were not passed off as read primers. Standings belong to ordinary Commander source lists, not these unplayed adaptations. No experimental unbans, price activation or combo surcharge. Earlier Batch1 artifacts are preserved. Batch3 awaits organizer review.

The original historical calculator remains intact; use score_batch2.py for these latest working prices. Local construction was read-only/in-memory; GitHub connector publication does not synchronize the local checkout.
